# Countdown-Timer-JS
 A responsive Countdown Timer built using HTML, CSS, and JavaScript that displays days, hours, minutes, and seconds remaining until a target date.

## Features

* Live countdown updates every second
* Displays days, hours, minutes, and seconds
* Animated progress bar
* Clean and responsive design
* Automatic expiration message when the countdown ends

## Technologies Used

* HTML5
* CSS3
* JavaScript
